
# Smart Agro Advisor – AI Agricultural Decision Support

A full-stack ML web application built with Flask, Random Forest, and Decision Trees for crop recommendations, disease prediction, and market price forecasting with 85%+ accuracy. Integrated with voice assistance to improve accessibility for farmers.

## Features
- **Crop Recommendation**: Recommends optimal crops based on N-P-K soil nutrients, pH, temperature, humidity, and rainfall.
- **Plant Disease Prediction**: Identifies diseases based on visual symptoms and environmental conditions.
- **Market Price Forecasting**: Predicts future market prices to help farmers time their sales.
- **Voice Assistance**: Built-in Web Speech API integration for hands-free voice input and Text-to-Speech (TTS) output.
